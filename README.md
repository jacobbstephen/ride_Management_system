Ride booking system in java

This is a simple java based ride booking system that simulates how users can book rides using different vehicle types[ car, auto, bike ], and drivers are assigned dynamically.
It also supports key features such as booking a ride, cancelling a ride, rating a ride, completing the ride, basic payment simulation.

 Features

- 👥 User creation
- 🚘 Driver registration with vehicle types
- 📍 Ride booking for:
  - Bike
  - Auto
  - Car
- 💳 Payment simulation:
  - UPI
  - Cash
- ❌ Ride cancellation
- ✅ Ride completion
- ⭐ Ride rating
- 📂 Repository for storing rides and drivers

📚 Purpose
This project was done to understand the structuring of code based on OOPS principles such as abstraction, encapsulation, inheritance, and polymorphism.
The aim was to simulate a real-world scenario while applying clean code architecture.

🗂️ Entry Point: The root file of this project is RideApp.java.
